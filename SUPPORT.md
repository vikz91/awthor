# Support

Use [GitHub Discussions](https://github.com/vikz91/awthor/discussions) for setup help, ideas in progress, and general questions. Use an issue form only for a reproducible bug or a well-defined feature request.

Before asking for help, remove or replace private manuscripts, backups, tokens, and account details. Awthor maintainers cannot recover browser-local data that has been cleared; keep regular backups.
